L'Exil Scolaire : Overseas Students' Journey (INSEE Dataviz 2025)

Finalist project (3rd / 17) for the national INSEE Dataviz Competition. Conducted an in-depth statistical investigation into educational mobility inequalities and structural gaps facing students moving from French Overseas Territories to Mainland France. Developed custom visual flows and spatial representations to highlight regional disparities in higher education access.

BST-Intervals-GTK-GUI

Interactive desktop application engineered in C using GTK3 for dynamic Binary Search Tree (BST) operations storing integer intervals. Implements real-time visual dynamic rendering, live memory allocation tracking, tree recentering, zoom mechanics, and a robust undo/redo action history engine (Ctrl+Z / Ctrl+Y). 2026 - present

Geometric Quantification of Semantic Class Bias

Comparative diachronic research evaluating latent socioeconomic and class stereotypes embedded across historical corpora. Triangulates static baselines (Word2Vec) against native Transformers (CamemBERT-base) and domain-adapted models (CamemBERT-Gutenberg) using a validated lexicographical dictionary (WOLF/TLFi) to analyze how continued pre-training revives structural class biases in downstream masked language modeling tasks.

2026 - present

FairCut : Autonomous Algorithmic Fairness & MLOps Pipeline

Production-ready MLOps infrastructure predicting daily box-office success via TMDB and XGBoost while auditing algorithmic bias across demographic cohorts using Fairlearn and Evidently AI. Features automated daily ingestion, data drift detection, continuous model retraining, automated promotion via MLflow, and full IAC deployment with Terraform and GitHub Actions onto an interactive Streamlit dashboard. (Collab: Lina Lebbah)
