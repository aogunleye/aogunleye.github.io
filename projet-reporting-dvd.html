SAE Reporting DVD : Analyse et extraction de données d'un historique de location

1. Contexte du projet

Ce projet a été réalisé en groupe pendant ma première année de BUT. On a travaillé sur une grosse base de données (Sakila) qui simulait l'activité d'une chaîne de magasins de location de films. En nous mettant dans la peau de Data Analysts, notre but était d'explorer les liens entre les clients, les films, les magasins, les paiements et les différentes villes.

2. Objectifs et Contraintes

Objectifs :

  • Interroger la base : Écrire des requêtes SQL pour extraire les bons historiques de location.
  • Calculer des indicateurs : Trouver des infos utiles pour le commerce, comme combien un client dépense en moyenne ou le chiffre d'affaires de chaque magasin.
  • Analyser les tendances : Comprendre les habitudes de location en regardant les horaires et les zones géographiques.

Contraintes :

  • Gérer les liens entre les tables : Il fallait bien maîtriser les jointures en SQL pour ne pas perdre ou doubler des données en traversant les différentes tables.
  • Rendre ça lisible : On devait résumer de gros volumes de données pour que ce soit facile à comprendre et utile pour prendre des décisions.
3. Compétences travaillées & Montée en compétence

Ce projet m'a permis de valider des bases importantes :

  • Bases de données (SQL) : J'ai beaucoup utilisé les fonctions pour regrouper et lier les données (SELECT, JOIN, GROUP BY, HAVING).
  • Création de tableaux de bord : J'ai appris à faire des rapports clairs sur Excel pour aider à la prise de décision.
  • Travail en équipe : On s'est bien organisés pour répartir les analyses et mettre en commun notre code.

La plus grosse difficulté a été de relier une dizaine de tables différentes en SQL, ce qui créait souvent des erreurs ou des lignes en double.

  • Comment on a fait : On a testé notre code étape par étape, en vérifiant le nombre de lignes avant et après chaque lien.
  • Ce que ça m'a appris : Cette méthode m'a aidé à vraiment bien comprendre comment fonctionnent les bases de données et à écrire des requêtes fiables.
4. Commentaire des résultats

En fouillant dans les données, on a trouvé des informations intéressantes pour l'entreprise :

  • Ce qui marche le mieux : On a pu voir exactement quels types de films sont les plus loués et quel magasin rapporte le plus.
  • Les moments de pointe : On a montré avec des graphiques qu'il y a plus de monde le soir et le week-end, ce qui aide à mieux organiser les plannings.
  • Validation finale : On a rendu un dossier pro et fait une présentation orale fluide, ce qui a prouvé qu'on savait transformer des données brutes en informations utiles.
5. Preuves et Documents

Voici ce qu'on a rendu à la fin du projet :

  • Code SQL : Le script avec nos requêtes pour extraire, filtrer et lier les données.
  • Fichier Excel : Le tableau de bord final avec nos analyses, graphiques et tableaux croisés dynamiques.
  • Présentation : Le diaporama (PPT) qu'on a utilisé pour présenter nos résultats au jury.
